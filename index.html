MetaText Spec

v1 · .metatext.jsonc

An open, human-readable JSONC sidecar metadata format (<file>.metatext.jsonc) for CSV, TSV, JSONL, and Log files. Persist column layouts, parsing rules, filter presets, row bookmarks, and conditional highlights without ever touching raw data files.

CSV・TSV・JSONL・Log などのプレーンテキストに対して、元ファイルを一切汚さずに 列幅・パース設定・フィルタプリセット・行マーカー・条件付き書式・セル装飾を外付け保存する オープンな JSONC サイドカー仕様（<file>.metatext.jsonc）です。

Canonical JSON Schema URL (v1) 公式 JSON Schema URL（v1）
https://mahorobalab.github.io/metatext-spec/schemas/v1/metatext.schema.json Open JSON

Quick Start クイックスタート

Place data.csv.metatext.jsonc next to data.csv. Adding $schema enables completion, hover docs, and validation in VS Code and other editors.

data.csv の隣に data.csv.metatext.jsonc を配置します。先頭に $schema を入れることで、VS Code などのエディタで入力補完・ホバー説明・バリデーションが効きます。 

{
  "$schema": "https://mahorobalab.github.io/metatext-spec/schemas/v1/metatext.schema.json",
  "version": "1.0",
  "format": "csv",
  "table": {
    "freezeColumns": 1,
    "defaultRowHeight": 28
  },
  "columns": {
    "amount": { "align": "right", "numberFormat": "#,##0" }
  }
}
